1. pwd: Su anki konumu gosterir
2. cd:Klasorler arasi gecis yapar
3. touch: bos yeni klasor olusturur
4. ls: Klasor icindeki dosyalari listeler
5. mkdir: Yeni klasor olusturur
6. git init: Yeni bir Git reposu baslatir.
7. git status: Tüm degisiklikleri gosterir.
8. git add: Degisiklikleri staging area'ya aktarır.
9. git commit -m : Staging'deki degisiklikleri version olarak kaydeder.
10. git log: Commit gecmisini listeler.
